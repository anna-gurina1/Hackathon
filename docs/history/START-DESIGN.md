# Bitwise: обновление интерфейса

Начните с этого файла. Это обновление приложенного проекта, не новый сайт и не новая система аккаунтов. Старые документы сохранены как история предыдущих доработок.

## Что сделано

- Сохранены логотип, фиолетовый/лаймовый/чёрный бренд, Manrope и Unbounded, Flask/Jinja и обычный JavaScript.
- Главная: понятнее первый экран, опубликованные курсы прямо на главной, сценарий «обучение → проверка знаний → возможность предложения работы».
- Каталог: читаемые карточки, фильтр по существующему полю Topic («Направление»), поиск и фильтры в адресной строке. Ссылкой на выдачу можно поделиться.
- Поиск работает и обычной GET-формой без JavaScript. С JavaScript результаты обновляются без перезагрузки; старый медленный ответ не подменяет новый, есть сброс и повтор после ошибки.
- Светлая/тёмная тема: сначала настройка системы, затем сохранённый выбор пользователя. Фото и логотип не инвертируются.
- Мобильное меню, клавиатурный фокус, переход к содержимому, общий подвал, единые отступы и кнопки, компоновка тарифов.
- Сохранены учебные тесты и автоматические проверки. Добавлены 10 тестов каталога.

Это этап улучшения интерфейса. Несколько произвольных тегов у каждого курса и новые полноценные курсы/видео в этом архиве НЕ добавлены. Направление использует существующее поле Topic, это не многотеговая система.

## Важно про данные

В архиве нет `.env`, настоящей базы, `.git`, виртуальной среды и данных демонстрационного аккаунта. Скриншоты в `design-preview/` сделаны на искусственных данных с пометкой «демо». После распаковки реальные курсы сами по себе не появятся: подключите копию своей базы или создайте учебные материалы через интерфейс.

Новые таблицы и миграции для этого обновления не добавлялись. Вход, роли, приглашения, учебный прогресс и механизм предложений работы не переписывались.

## Самый безопасный способ посмотреть

1. Не заменяйте общую рабочую папку команды. Сохраните её копию и распакуйте этот архив отдельно.
2. Откройте новую папку `Bitwise-improved` в VS Code: «Файл → Открыть папку».
3. Откройте терминал в VS Code: «Терминал → Создать терминал».
4. Установите Python, если команды `python --version` или `py --version` не работают. Проверенная среда — Python 3.13.
5. Создайте виртуальную среду.

Windows PowerShell:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
Copy-Item .env.example .env
.venv\Scripts\python.exe -c "import secrets; print(secrets.token_hex(32))"
```

Последняя команда покажет новый ключ. Вставьте его в `SECRET_KEY=` в вашем `.env`. Это ваш локальный секрет, не отправляйте его в чат и не коммитьте. Оставьте `APP_ENV=development`, `HOST=127.0.0.1`, `DATABASE_URL=` пустым для отдельной локальной SQLite-базы. Реальные облачные и почтовые ключи для просмотра дизайна не нужны.

macOS / Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
cp .env.example .env
.venv/bin/python -c "import secrets; print(secrets.token_hex(32))"
```

6. Для НОВОЙ пустой локальной базы примените существующие миграции.

Windows:

```powershell
.venv\Scripts\python.exe -m flask --app run db upgrade
.venv\Scripts\python.exe run.py
```

macOS / Linux:

```bash
.venv/bin/python -m flask --app run db upgrade
.venv/bin/python run.py
```

7. Откройте адрес, показанный в терминале: обычно `http://127.0.0.1:5000`. Остановить сервер — Ctrl+C.

Если хотите увидеть интерфейс ещё до запуска, откройте PNG-файлы в `design-preview/`. Это снимки, не интерактивный сайт.

## Если у вас уже есть база

Не запускайте миграции на настоящей базе без резервной копии и согласования с командой. Для текущего обновления схемы базы менять не требуется. Сначала подключите отдельную копию базы на своей машине; не используйте production DATABASE_URL для экспериментов.

Для SQLite в ИСХОДНОЙ папке проекта:

```bash
python tools/backup_sqlite.py app.db backups
```

Команда создаёт отдельную согласованную копию SQLite, исходник открывается только для чтения. Если используется PostgreSQL, резервную копию делайте средствами провайдера/pg_dump; SQLite-команда к нему не подходит. Сохраните также собственный `.env` и локальные загруженные файлы вне архива. Не удаляйте базу, чтобы «исправить» ошибку запуска.

Переносите обновление сначала в копию проекта, сохраняя её конфигурацию и данные. Список файлов — `DESIGN-CHANGED-FILES.txt`. Если код команды уже изменился после присланного архива, не перезаписывайте эти файлы вслепую: изменения нужно объединить.

## Как проверить

Windows:

```powershell
.venv\Scripts\python.exe -m pytest -q
.venv\Scripts\python.exe translations/check.py
```

macOS / Linux:

```bash
.venv/bin/python -m pytest -q
.venv/bin/python translations/check.py
```

В браузере:

1. Главная → «Найти курс» → карточка курса. Трудоустройство остаётся в объяснении процесса.
2. Каталог: текстовый поиск, направление, язык, поиск компаний. Попробуйте запрос без результатов и сброс фильтров.
3. Скопируйте адрес страницы каталога, откройте в новой вкладке; проверьте кнопку «Назад».
4. Переключите тему и обновите страницу. Тема должна сохраниться.
5. Уменьшите ширину окна примерно до 390 px: откройте меню, нажмите Escape, откройте вход/регистрацию.
6. С тестовым локальным аккаунтом проверьте личный кабинет и уже существующие сценарии компании и обучения.

При пустых почтовых настройках локальная версия выводит ссылки входа в ВАШ терминал. Это только режим разработки. Не публикуйте логи со ссылками и не используйте этот режим как production-почту.

Облачное видео/PDF, отправка настоящей почты и AI требуют отдельных настроек. Они не проверялись реальными ключами в этой работе. Оплата по-прежнему демонстрационная.

## Как передать команде

В своей рабочей копии Git создайте отдельную ветку, например `git switch -c ui/bitwise-refinement`. Ветка — отдельная линия изменений, не замена общей `main`. Проверьте `git diff` и `git status`, добавьте только нужные исходники, сделайте commit (сохранённый набор изменений), затем push своей ветки и pull request для обсуждения. Никогда не добавляйте `.env`, базы и резервные копии. В этом сеансе ветка, commit, push и публикация сайта не выполнялись.
