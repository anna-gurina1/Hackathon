# Bitwise — одна почта, личный кабинет и компании

Учебный проект на Flask + Jinja + обычных HTML/CSS/JavaScript. React и новые runtime-зависимости не добавлены.

## Что изменилось

- Один человек входит одной почтой, учится и работает с несколькими компаниями.
- Личный кабинет показывает свой курс как обычному ученику. Авторские права действуют только в выбранной компании. Выбор кабинета сразу открывает его, без кнопки «Переключить».
- Компания отделена от аккаунта. Название, логотип, тариф и курсы принадлежат компании.
- Владелец приглашает редактора на конкретную почту. Приглашение действует 7 дней и требует принятия.
- Редактор работает только с назначенными черновиками, не публикует курсы и не видит кандидатов.
- Опубликованный курс редактор менять не может. Права проверяет сервер, а не только кнопки.
- Как в исходном проекте, есть открытые и приватные курсы. Приватные видны в каталоге и на странице компании; обучение — после одобрения заявки или по ссылке-приглашению владельца.
- Публикация проверяет уроки, содержимое, тесты и защищённую доставку закрытых видео.

## Быстрый запуск в новой пустой папке

Нужен Python 3.12+; проверено на Python 3.13.

```bash
python -m venv .venv
```

Активируйте среду:

Windows PowerShell:
```powershell
.\.venv\Scripts\Activate.ps1
```

Если PowerShell запрещает активацию, не меняйте политику безопасности: выполняйте команды через `.\.venv\Scripts\python.exe` вместо `python`.

macOS / Linux:
```bash
source .venv/bin/activate
```

```bash
python -m pip install -r requirements-dev.txt
```

Скопируйте `.env.example` в `.env`, создайте секретный ключ и вставьте в `SECRET_KEY`:

```bash
python -c "import secrets; print(secrets.token_hex(32))"
```

Для локальной проверки оставьте `APP_ENV=development`, `DATABASE_URL=` пустым и `MAIL_SERVER=` пустым. Ссылки для входа будут печататься в вашем терминале. Не используйте этот режим на публичном сервере.

```bash
python -m flask --app run db upgrade
python run.py
```

Откройте http://127.0.0.1:5000. Зарегистрируйтесь, откройте ссылку из терминала, затем «Кабинеты и приглашения» → «Создать компанию».

```bash
python -m pytest -q
python translations/check.py
```

Миграции больше не запускаются незаметно при каждом импорте приложения. В обычном запуске выполняйте `flask ... db upgrade` явно. Контейнер запускает эту команду перед Gunicorn; при нескольких контейнерах миграцию следует вынести в единственный release-job.
