# Проверка обновления интерфейса

Дата: 27 октября 2026. Это проверка доработки, не полный аудит безопасности сайта.

## Подтверждено

- Исходная версия: **90 passed**.
- Обновлённая версия: **100 passed**, включая 10 новых тестов каталога. Последний запуск: 13.14 секунды.
- В pytest остаются 87 предупреждений об устаревающих API в проекте/зависимостях. Это не ошибки тестов, но их стоит разобрать отдельно; предупреждения не подавлялись.
- `translations/check.py`: **667 текстов, 0 проблем**. Отдельно выводятся 28 старых неиспользуемых переводов; они сохранены, а не удалены автоматически.
- `node --check`: `main.js`, `theme.js`, `tips.js` — синтаксических ошибок нет.
- В основных браузерных проверках — **31 успешная проверка**, включая рендеринг и взаимодействия; необработанных JavaScript-ошибок не обнаружено.
- Дополнительно проверены страницы урока, учебного теста, кабинета компании и конструктора на ширине 1440 и 390 px.
- На 320, 390, 768 и 1440 px выполнены 16 механических проверок отсутствия горизонтального переполнения на главной, в каталоге, карточке курса и тарифах. Ещё 2 проверки компоновки выполнены с CSS zoom 200% (это не проверка всех видов браузерного увеличения).

## Что проверялось в браузере

Локальный Chromium через Playwright, отдельная искусственная SQLite-база в памяти. Настоящие данные, почтовые ключи, Cloudinary и платные API не использовались.

- Главная, каталог и карточка курса — обе темы, 1440 и 390 px.
- Тарифы и личный кабинет — тёмная тема, 1440 и 390 px.
- Английский интерфейс — главная и каталог, 768 px. Пользовательский контент курса остаётся на исходном языке, как и раньше.
- Мобильное меню: открытие, Escape, возврат фокуса.
- Окно регистрации: переключение формы и Escape.
- Тема сохраняется после перезагрузки.
- Поиск, точное направление, комбинация с запросом и языком, пустая выдача, сброс.
- Состояние поиска в URL, возврат кнопкой «Назад».
- Режим компаний выключает фильтры, относящиеся только к курсам.
- HTTP 503 при поиске: понятная ошибка, кнопка повтора, успешное восстановление.
- Искусственно замедленный старый ответ не подменяет более новый результат.
- Отключённый JavaScript: серверная выдача и GET-форма каталога.
- Заблокированный localStorage не ломает поиск и переключение темы в текущей вкладке.
- Урок → учебный тест, переключение рабочего кабинета → кабинет компании → конструктор на демонстрационном аккаунте.

Снимки открывались по отдельности для визуальной проверки, а не только создавались. На тарифах исправлены отсутствовавшая сетка и интервалы; у подсказок в полях исправлен контраст в тёмной теме. Итоговые снимки выбранных страниц находятся в `design-preview/`.

## Новые тесты каталога

1. Главная показывает опубликованное, не черновики.
2. Выдача существует до выполнения JavaScript.
3. Направление фильтруется по точному значению; направления черновиков не предлагаются.
4. Направление сочетается с запросом и языком.
5. Приватная опубликованная карточка остаётся в каталоге по прежним правилам, черновики закрыты.
6. Неподдерживаемый режим GET-формы безопасно заменяется обычным поиском.
7. Пустая выдача предлагает сброс фильтров.
8. Поиск компаний рендерится сервером.
9. Пользовательские названия/направления экранируются в HTML.
10. На главной не больше трёх карточек, выборка ограничена запросом к базе.

## Не проверено / не входит

- Production-развёртывание, настоящая почта, защищённая доставка облачных видео/PDF, AI и реальные платёжные операции. Оплата остаётся демонстрационной.
- Safari, Firefox, реальные iOS/Android-устройства и полноценная проверка скринридером.
- Все редкие формы, состояния редактора/владельца и все варианты контента; основные права проверяются существующим pytest-набором, но это не исчерпывающий аудит.
- Core Web Vitals, позиции в поиске и конверсии. Публичный SEO-аудит без рабочего URL не проводился.
- Гарантия безопасности или отсутствия любых ошибок.
- Добавление нескольких произвольных тегов к каждому курсу, новых реальных курсов/видео и замена логотипа. Текущий фильтр использует существующий Topic.

Схема базы и существующие миграции не менялись. Ничего не публиковалось в GitHub/production. Архив не содержит исходную `.env`, настоящую базу, `.git`, кэши и виртуальную среду. Локальный служебный сервер с демонстрационным входом в архив не включён.
