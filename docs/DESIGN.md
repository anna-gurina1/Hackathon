# Bitwise — refinement, не смена бренда

## Решение

Сохранить вклад команды: исходный знак и слово Bitwise, Manrope для текста, Unbounded для заголовков, чёрную шапку, фиолетовые смысловые панели и лаймовые основные действия. Не заменять Flask/Jinja и обычный JavaScript. Развивать существующий дизайн, не переносить на сайт набор противоречащих друг другу стилей.

## Композиция

- Главная: существующее обещание продукта → курс из реальной опубликованной базы → пояснение трёх шагов → предложение компаниям.
- Desktop: герой слева, краткая схема обучения справа. Mobile: схема остаётся в подробной секции ниже, первый экран сфокусирован на поиске курса.
- Каталог: заголовок → форма поиска и фильтров → счётчик/состояние → карточки. В карточке направление и язык, компания, название, описание, уровень и число уроков.
- Никаких вымышленных отзывов, работодателей, чисел трудоустройства или обещания гарантированной работы.
- Максимальная ширина контейнера 1184 px, читаемая длина абзаца, внешние поля 20–32 px. Три колонки на широком экране, две на промежуточном, одна на телефоне.

## Поведение

Тема следует системе до первого выбора. GET-форма каталога работает без JavaScript; JS лишь улучшает обновление. Общая навигация доступна с клавиатуры, в меню есть Escape, видимый фокус, у модального окна сохраняется нативный dialog. Не добавлять декоративные анимации: это учебная рабочая среда. Важные сообщения не исчезают по таймеру.

Полная многотеговая система, редакционная подборка реальных курсов и переработка внутренних сценариев — отдельные следующие задачи, не часть этого визуального обновления.

## Дополнительная полировка

Карточки получили ненавязчивый сетевой мотив, который перекликается с исходным знаком Bitwise, а не вымышленные обложки уроков. В подвале повторён оригинальный логотип. Акцент для компаний сохранён лаймовым. Состояние карточки с фокусом клавиатуры равноценно наведению мыши; короткие переходы отключаются при reduced motion. В режиме forced colors декоративная сеть скрывается.
