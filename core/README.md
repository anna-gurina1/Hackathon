# core/ — лид

Сборка приложения и база вопросов.

- `__init__.py` — `create_app()`: подключает базу, вход, блюпринты из `backend/routes`, шаблоны из `frontend/`
- `config.py` — настройки (секретный ключ, база, папка видео, почта)
- `questions.py` — вопросы мастеру, длительности, шаблоны тестов
- `run.py` и `requirements.txt` в корне — тоже здесь в зоне ответственности

Новый блюпринт из `backend/routes/` регистрируется в `create_app()` — скажите лиду.
