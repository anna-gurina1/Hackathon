# Database

- `models.py` — таблицы и отношения; изменение схемы требует миграции.
- `catalog.py` — SQL каталога, агрегатные счётчики уроков и публичные данные карточек.
- `queries.py` — личный кабинет, компания, оценки и видимость курса. Старые имена поиска переэкспортируются для совместимости.
- `seed.py` — существующие демонстрационные данные; не удалён ради уменьшения размера.
