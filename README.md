# Bitwise

Обучение у экспертов компаний: курс → проверка знаний → возможность предложения работы. Учебный проект на **Flask, Jinja, SQLAlchemy и обычном JavaScript**, без React и сборщика frontend.

## С чего начать

- **[START-HERE.md](START-HERE.md)** — установка, пробный запуск и безопасное обновление вашей рабочей папки.
- **[docs/CODE-GUIDE.md](docs/CODE-GUIDE.md)** — в каком порядке читать код и где менять конкретные функции.
- **[ARCHITECTURE.md](ARCHITECTURE.md)** — модель данных и обязательные правила доступа.
- **[REFACTOR-REPORT.md](REFACTOR-REPORT.md)** — что изменено, измерения и ограничения проверки.
- **[docs/DESIGN.md](docs/DESIGN.md)** — оформление; в `design-preview/` — снимки интерфейса на искусственных данных.

## Структура

```text
run.py                  запуск локального сервера
core/                   создание приложения, конфигурация, учебные вопросы
backend/routes/         HTTP-маршруты и ответы
backend/catalog.py      общая обработка фильтров каталога
backend/access.py       серверная проверка прав
backend/uploads.py      работа с внешним хранилищем
backend/email.py         отправка писем
backend/translator.py   перевод пользовательских текстов
backend/i18n.py          язык интерфейса
backend/plans.py         демонстрационные тарифы
database/models.py      таблицы и отношения
database/catalog.py     SQL каталога и карточки результатов
database/queries.py     кабинеты, результаты и видимость курсов
frontend/templates/     Jinja HTML
frontend/static/        CSS, JS, изображения
translations/ru/        переводы интерфейса
migrations/             история схемы базы — не удалять
tests/                  автотесты — не участвуют в обычном запуске
tools/                  резервная копия SQLite
docs/                   руководство по коду, дизайн и история
```

## Две зависимости для двух задач

```bash
# Только запуск сайта:
python -m pip install -r requirements.txt

# Разработка и автотесты (также устанавливает requirements.txt):
python -m pip install -r requirements-dev.txt
```

`tests/` не нужны серверу во время работы, но нужны команде перед изменениями. Не удаляйте их ради «оптимизации»: это не ускорит страницы. Учебные тесты внутри курсов — другая функция; она сохранена.

## Команды проверки

```bash
python -m pytest -q
python translations/check.py
```

Автотесты используют отдельную SQLite-базу в памяти и подменённую отправку писем. Это не проверка настоящего SMTP, Cloudinary, AI или производственной нагрузки.

В `docs/history/` сохранены предыдущие инструкции и результаты; они могут описывать старые версии. Для текущего запуска используйте только START-HERE.md. Схема базы, дизайн, роли, вход, обучение и трудоустройство этим рефакторингом не менялись.
